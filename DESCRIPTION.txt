1. WHAT IS THIS PROJECT?
--------------------------------------------------------------------------------

The Student Grade Management System (SGMS) is a console-based Java
application that helps educational administrators manage student academic
records — students, courses, and the grades they earn — all from a single
menu-driven interface.

It removes the mess of spreadsheets and paper registers by providing:
   * One place to add, update, view, and delete students
   * One place to manage the course catalog
   * Automatic conversion of raw marks to letter grades (A+, A, B+, B, ...)
   * Weighted CGPA calculation
   * Formatted transcripts and course statistics on demand

The application stores its data in simple CSV files, so it works on any
machine with just a JDK installed — no database, no web server, no extra
libraries.


--------------------------------------------------------------------------------
2. WHY WAS IT BUILT?
--------------------------------------------------------------------------------

In many small academic setups, student grades are tracked manually in
spreadsheets. This causes:

   * Inconsistent data (multiple people editing different copies)
   * Slow transcript generation
   * Errors in manual CGPA calculation
   * No standardised course statistics

SGMS solves all four problems with a single, consistent Java application
that automates record keeping, grade conversion, CGPA calculation, and
report generation.


--------------------------------------------------------------------------------
3. KEY FEATURES
--------------------------------------------------------------------------------

   * Student Management  — full CRUD on student records
   * Course Management   — full CRUD on the course catalog
   * Grade Management    — record marks, automatic letter-grade mapping
   * CGPA Calculation    — credit-weighted, per-student
   * Transcripts         — formatted per-student academic report
   * Course Statistics   — average, highest, lowest marks per course
   * System Summary      — total counts across the system
   * File Persistence    — data survives application restart
   * Input Validation    — type checks, range checks, duplicate checks
   * Error Handling      — graceful messages, no stack traces to users


--------------------------------------------------------------------------------
4. TECHNICAL DESIGN
--------------------------------------------------------------------------------

The project follows a three-layer architecture:

   Presentation Layer  :  Main.java              (menu UI)
   Business Layer      :  StudentManager,
                          CourseManager,
                          GradeManager           (CRUD + logic)
   Model Layer         :  Student, Course, Grade (entities)
   Utility Layer       :  FileHandler,
                          ReportGenerator        (helpers)

Package Structure:
   src/
     model/      POJOs representing students, courses, grades
     manager/    Business logic for each entity
     util/       File I/O and report generation
     Main.java   Entry point + console menu

Object-Oriented Programming concepts demonstrated:
   * Encapsulation   — private fields + getters/setters
   * Abstraction     — managers hide CSV read/write from callers
   * Modularity      — clean package separation
   * Composition     — grades reference student + course objects
   * Validation      — constructor / setter argument checks


--------------------------------------------------------------------------------
5. NON-FUNCTIONAL HIGHLIGHTS
--------------------------------------------------------------------------------

   * Performance     : in-memory ArrayList, O(n) lookup, sufficient for
                       small academic datasets
   * Security        : input validation, duplicate-ID rejection, range checks
   * Usability       : clear menu UI, formatted tables, helpful messages
   * Reliability     : all file I/O wrapped in try/catch, malformed lines
                       are skipped, never crash the app
   * Maintainability : single-responsibility classes, Javadoc comments,
                       strict package boundaries


--------------------------------------------------------------------------------
6. HOW TO RUN
--------------------------------------------------------------------------------

   cd student-grade-management
   mkdir -p out
   javac -d out src/model/*.java src/manager/*.java \
                  src/util/*.java src/Main.java src/test/*.java
   java -cp out Main

A self-contained validation test suite is also included:
   java -cp out test.ValidationTest
